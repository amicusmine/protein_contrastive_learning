🚀 三种使用方式
═══════════════════════════════════════════════════════════════════════

【方式1】一键运行（最简单）
   cd protein_contrastive_learning
   python run_all.py

【方式2】分步执行（推荐学习）
   python quick_test.py                    # 测试环境
   python data_preparation.py              # 准备数据
   python train.py --epochs 20             # 训练模型
   python evaluate.py                      # 评估结果
   python demo.py                          # 查看示例

【方式3】自定义训练
   python train.py \
       --epochs 100 \
       --batch_size 16 \
       --hidden_dim 256 \
       --output_dim 512
